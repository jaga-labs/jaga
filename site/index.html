About JAGA

Data First. Models Second.

Most low-resource NLP work starts with models. JAGA starts with understanding the language itself — through data collection, structured analysis, and gap identification.

📊

Dataset-Centric

Track, analyze, and expand datasets with measured gaps — not assumptions. Every dataset is registered with metadata, statistics, and provenance.

🔍

Gap Analysis

Identify missing domains, weak linguistic coverage, and data imbalance. Targeted collection fills exactly what's needed.

🔄

Iterative Pipeline

New data → analysis → model → improvement → repeat. Each cycle improves dataset quality, model robustness, and language coverage.

Core workflow: language → data → analysis → gaps → targeted collection → models

Progress

Project Roadmap

JAGA follows a structured, phased approach where each stage builds on validated data and analysis.

JAGA v0.1 — Odia Foundation

Analyze existing Odia datasets · Build analysis pipeline · Collect 10 hours of domain-tagged speech · Establish baseline ASR · Identify key linguistic gaps

JAGA v0.2 — Expansion

Implement adaptive/exception-aware decoding · Expand dataset coverage (science, numerics) · Improve quality through iteration

JAGA v1.0 — Mature Infrastructure

Mature Odia language infrastructure · Standardized datasets + benchmarks · Extend pipeline to additional Indic languages

Research Areas

Focus Areas

JAGA covers multiple dimensions of language technology, all driven by data analysis.

🎙️

Speech Systems

Speech datasets, ASR (speech-to-text), text-to-speech, speech-to-text translation, and speech understanding beyond transcription.

📚

Language Resources

Parallel corpora, scientific and educational vocabulary, linguistic structure analysis, and domain-specific terminology.

🧠

Models

Low-resource ASR, efficient decoding (adaptive/exception-aware), and lightweight language models optimized for Indic languages.

All datasets are organized under datasets/<language_code>/ — with full metadata, analysis, and provenance documentation.

Open Source

Contribute to JAGA

JAGA is designed as an open system. Every contribution follows a structured proposal → validation → integration workflow.

📦 Existing Datasets

Add publicly available datasets with source, metadata (hours, domains, license), and a justification of what gap it fills.

🆕 New Datasets

Create domain-specific datasets (education, science, literature). Provide collection method, expected size, and transcript availability.

🌐 New Languages

Propose new Indic languages or dialects. Specify language code, classification, estimated sentence count, and linguistic differences.

View on GitHub →

All contributions start with an issue. No pull requests without prior discussion.
