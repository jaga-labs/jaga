What is JAGA

A Registry. A Community. A Record.

JAGA tracks every publicly available Odia language dataset — so researchers, developers, and linguists don't have to start from scratch.

📂

Dataset Registry

A curated index of all known Odia datasets — speech, text, parallel corpora — with source links, licenses, size, and domain coverage.

🎙️

Dialect Collection

An active effort to record Odia dialects across Odisha's 30 districts. Each dialect is a living piece of the language — we want to preserve all of them.

🔍

Gap Analysis

We analyze what exists and surface what's missing — underrepresented domains, untouched dialects, and sparse speaker demographics.

Speech Public

OpenSLR Odia ASR Corpus

~4 hours of read speech from OpenSLR (IIIT-H). Recorded in a controlled environment. Limited domain and speaker diversity.

~4 hrs·CC-BY·Read speech

Text Public

Odia Wikipedia Corpus

Text extracted from Odia Wikipedia. Useful for language modelling but skewed toward formal/encyclopaedic register.

~200k articles·CC-BY-SA·Formal text
View Source ↗
Parallel Public

OPUS / IndicGLUE Odia

Odia-English parallel text from OPUS and IndicGLUE benchmark. Useful for translation and cross-lingual tasks.

Various sizes·Mixed·Parallel text
View Source ↗
Speech Public

MUCS / Shrutilipi Odia

Multi-speaker Odia speech from the MUCS challenge and Shrutilipi project. One of the larger Odia speech collections.

~40 hrs·Research use·Read speech
